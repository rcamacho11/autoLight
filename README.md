# autoLight

I got annoyed that Windows was missing one of my favorite features from Android, iOS, and macOS: automatically switching between light and dark mode based on the time of day.

So I built **autoLight**, a lightweight utility that brings this functionality to Windows. My goal was to make it as lightweight as possible, with virtually no impact on system performance or battery life, as if it weren't even running.
